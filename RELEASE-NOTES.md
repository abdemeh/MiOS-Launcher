# MiOS Launcher 6.10.21

First MiOS-branded release, based on and inspired by [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv).

- New MiOS Launcher name, icon and TV banner; versionName 6.10.21 / versionCode 6.
- Blurred color backgrounds, ten themes and configurable clock screensaver.
- Shared Home/Apps selection with working checkboxes; Home shows the first two rows.
- Focus-based Home/Apps navigation, smooth transitions and card actions.
- HDMI/input controls with centered header icon and connection indicators.
- Custom app artwork including Downloader, Speedtest and AnyDesk.

Download MiOS-Launcher.apk below. Install it on the TV or use adb install -r. The package remains com.gathin.tvhome and the original signing identity is preserved for updates from this project's earlier builds.

Tested on Xiaomi MiTV-MOOR2 / Android 11. Other TVs need device-specific verification. Installing the APK does not automatically debloat the TV or enable the optional Home override. See the repository README for installation, screenshots and setup.
