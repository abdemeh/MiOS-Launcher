# Xiaomi UI adaptation of the supplied visual reference

The user's reference is preserved in UI-REFERENCE.md. It is a design reference rather than
an instruction to replace firmware or change hardware services. Earlier direct user choices
remain in effect: six editable favorites, dynamic color blur without photographs, and the
supplied standard SF Pro Display font family (including bold headings).

## Implemented

- Safe-area Home with Home / Apps / Search glass navigation, compact clock and hardware shortcuts.
- Local top shelf: 44sp Display Bold app title, honest service description, Open action and a
  subdued installed-app banner/icon. Title transitions are interruptible. Background uses the
  selected app color with three cached soft orbs. No promotional feeds or invented watch data.
- Six favorites at the bottom; Down reveals the full grid, Back restores Home, and Search
  filters installed apps locally. Search supports case folding, accent normalization and
  multiple terms, including non-Latin scripts.
- Floating focus: 8.5% scale, lift shadow, directional tilt settling to 0.6 degrees, layer
  parallax, one sheen sweep, a faint inner edge, focus-only labels and subtle neighbor movement.
  Fast D-pad repeats skip expensive effects. Tile animations stop when detached.
- App launches use Android's scale-up activity option from the focused tile. Return behavior
  remains partly controlled by each external app; full reverse shared-element motion is not promised.
- Hold Select to move an app; visible tiles gently jiggle during editing. OK drops and Back saves.
  The Edit button also supports replacing favorites and rearranging the catalog.
- Shared dark glass panels for Inputs, Network and Control Center, with white focus inversion.
- Two-pane settings: Home Screen, Appearance, Screen Saver, Network, Display & Sound, Apps,
  Accessibility and System. Options include color intensity, hero visibility, clock size/weight,
  date position, preview, and reduced motion. Firmware-owned controls open native TV pages.
- Large SF Pro Display clock and date over color blur. Original Android idle timing retained.

## Adaptations and boundaries

The existing native Android View implementation is retained for Android 11 compatibility and
low memory use; no framework migration or new runtime dependencies were required. Tile sizing
fits six columns within the actual 960dp screen: six 200dp tiles from the approximate spec
would exceed the screen width. Apps and Library share one catalog rather than duplicate tabs.

Folders, external hero/content feeds, autoplay preview video and full cross-application reverse
transitions are not implemented. The user explicitly chose blur instead of photo/video backgrounds.
No Apple logos, wallpapers, aerial footage or replacement Apple app icons were added.

## Aurora clock and editable SVG update

Home, settings and the idle clock reuse a cached 1920x1080 aurora bitmap, generated by tools/prepare_tv_assets.py from assets/backgrounds/aurora.json. The supplied palette and light positions are rendered as Gaussian fields with screen blending, approximate blur and contrast grading to approach the reference. One explicit focus path now owns all four D-pad directions. The old native focus-search scrolling, deferred scroll-idle listener, layout-entry animations and legacy ambient/hero animations no longer compete with navigation. ## Favorites checkbox picker refresh

Settings > Home Screen > Edit favorites lists all launchable installed apps except this launcher and reserved recovery launchers. OK toggles a visible checkbox and immediately saves Home membership without launching an app, changing catalogue order, or moving to another card. Unchecked apps are hidden from both Home and Apps, but remain installed and available in the favorites checklist. Membership is read from stored choices, independent of the current page/search or displayed rows; Home shows the first two rows of the selection; Apps shows all selected apps in the same order. Existing default membership is preserved. The latest incoming/anydesk.svg is bundled. Included in the user-authorized v0.1 refresh.

HDMI alignment refresh: the 19dp header icon now has 7.5dp horizontal padding inside its 34dp circle, centering it without changing the icon size or input behavior. Included in v0.1.

Shared selection correction: Home and Apps use the same saved checkbox choices. Home shows only the first two rows; Apps shows the whole selected list. The favorites checklist always lists installed launchable apps independently, including unchecked ones, so they can be restored. Hiding an app does not uninstall it or disable Live TV/input services. Included in the user-authorized v0.1 refresh.
